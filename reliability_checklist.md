# Reliability Checklist

## 1. Safety Check

I confirmed that the report and memo contain only region-level aggregated performance information and do not include any personally identifiable customer information.

## 2. Validation

I checked all sales values and month-on-month percentage changes against the SQL-derived Part 2 metrics before using them in the report.

## 3. Critique and Refine

I reviewed the narrative to remove unsupported explanations and ensured that possible causes were treated as hypotheses rather than facts.

## 4. Human Sign-off

The final memo and narrative must pass the review gate with an `approve` decision before they are allowed to be used downstream.
